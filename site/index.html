Mario Kart Wii,
native on PS Vita.

Not an emulator. A native port of MKW-3DS, the 1:1 3DS recreation of Mario Kart Wii (not of the Wii game itself), running on the Vita's own APIs with vitaGL. Now in two editions: Mario Kart Wii, and MKW Retro Rewind with 310 tracks.

Latest VPKs Retro Rewind edition View on GitHub Build guide

How it works

The 3DS game code runs as-is, on top of a small layer that speaks Vita.

Real MKW physics

Kart handling comes from Kinoko, a faithful recreation of Mario Kart Wii's physics engine.

Native game code

Menus, races, items and CPU racers are MKW-3DS's native code, compiled for the Vita.

3DS → Vita layer

libctru and citro3d re-implemented: the 3DS GPU's combiners become generated GLSL shaders, and a software mixer replaces the DSP.

No Nintendo files

The repo ships no game data. You build the game files yourself from your own disc.

Settings

Tap Settings under Start on the game's LiveArea (close the game first), change what you like, then Save and Start or Save and Exit.

The graphics settings live in ux0:data/mkw/quality.txt, which you can still edit by hand; the values in use are written to ux0:data/mkw/vita.log at start-up.

Get it running

You'll need a hacked Vita (HENkaku / Ensō), a Mario Kart Wii (USA) disc dump and a Windows PC. Mario Kart Wii first; MKW Retro Rewind below.

  1. Download mkw.vpk from the latest release.
  2. Build the game files: double-click Build Game Files.bat (from the same release's source code), drag your disc image into the window and press Enter. The first build takes 30–60 minutes. On macOS or Linux, run python3 build-game-files.py from the source folder instead and paste in your disc image's path. You'll need tex3ds first; see the macOS/Linux guide. Building the VPK yourself? Use Build MKW Vita.bat instead (needs VitaSDK).
  3. Install the VPK with VitaShell.
  4. Copy the contents of build\vita\data\mkw\ to ux0:data/mkw/ on the Vita.
  5. Make sure ur0:data/libshacccg.suprx is extracted (use ShaRKF00D), then launch from the LiveArea and pick an empty slot to make your license.

MKW Retro Rewind

You'll also need Retro Rewind 6 installed on your PC (the RetroRewind6 folder from Dolphin or WheelWizard), about 45 GB free on the PC and 8 GB on ux0:.

  1. Download mkw-retro-rewind.vpk from the latest release.
  2. Unzip the same release's source code into its own folder, not the one you build Mario Kart Wii in: one folder builds one edition.
  3. Double-click Build Retro Rewind Game Files.bat, drag in your disc image, then your RetroRewind6 folder (or press Enter to use Dolphin's). The first build takes a few hours. Building the VPK yourself? Use Build MKW Retro Rewind Vita.bat.
  4. Install the VPK and copy the contents of build\vita\data\mkwrr\ to ux0:data/mkwrr/, then launch MKW Retro Rewind from the LiveArea.

Updating from 1.2.0? Build the game files again from the 1.3.0 source: the VPK and the game files must come from the same release. Your best times and ghosts move into the first license you create.

Please don't share the built game files: they contain Nintendo's data. Full requirements and troubleshooting are in the README and BUILDING.md.
