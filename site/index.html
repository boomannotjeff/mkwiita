How it works

The 3DS game code runs as-is, on top of a small layer that speaks Vita.

Real MKW physics

Kart handling comes from Kinoko, a faithful recreation of Mario Kart Wii's physics engine.

Native game code

Menus, races, items and CPU racers are MKW-3DS's native code, compiled for the Vita.

3DS → Vita layer

libctru and citro3d re-implemented: the 3DS GPU's combiners become generated GLSL shaders, and a software mixer replaces the DSP.

No Nintendo files

The repo ships no game data. You build the game files yourself from your own disc.

Get it running

You'll need a hacked Vita (HENkaku / Ensō), a Mario Kart Wii (USA) disc dump and a PC.

  1. Download mkw.vpk from the latest release and install it with VitaShell.
  2. Run Build Game Files.bat from the same release's source code and drag in your disc image (30–60 minutes the first time). On macOS or Linux, see this guide.
  3. Copy the contents of build\vita\data\mkw\ to ux0:data/mkw/.
  4. Make sure ur0:data/libshacccg.suprx exists (run ShaRKF00D once), then launch.

MKW Retro Rewind

  1. Download mkw-retro-rewind.vpk and unzip the release's source into its own folder.
  2. Run Build Retro Rewind Game Files.bat, drag in your disc image, then your RetroRewind6 folder (a few hours and about 45 GB the first time).
  3. Copy the contents of build\vita\data\mkwrr\ to ux0:data/mkwrr/.

Updating from 1.4.x? Just install the new VPK: 1.4.2 uses the same game files. From an older release, build the game files again from the new release (the VPK and the game files must come from the same one) and delete the old .pak files on the Vita before copying the new ones.

Please don't share the built game files: they contain Nintendo's data. More in the README and BUILDING.md.
